# 5 分钟上手与验收清单

本文给评审用：装好、启动、按清单逐条手动验证。5 条断言里第 1、2、3、5 条不需要 API Key；第 4 条需要先配一把有效 Key 存下技能，再故意把 Key 改错。

命令与口径与 [README.md](../README.md) 一致：项目名「凌零 · 桌面 AI 数字员工」，仓库 github.com/hm-yep/L-Agent。

## 准备

```bash
pip install -r requirements.txt
```

无 Key 启动（Windows / Linux 相同，桌面版默认 `USE_REAL_AI=False`）：

```bash
python main.py
```

需要真实模型时再配 Key，Key 只写在本机环境变量或启动后的设置界面里，不进仓库：

```bash
# Windows (CMD)
set DEEPSEEK_API_KEY=你的Key
python main.py

# Linux / macOS
export DEEPSEEK_API_KEY=你的Key
python main.py
```

验证过程中产生的待办、记忆、技能、交付都落在 `data/` 下的本地 JSON 与文件里，该目录已被 `.gitignore` 排除，可随时清理。

## 验证清单

### 断言 1：无 Key 也能执行工具动作（离线规则兜底）

**操作**

1. 确认环境变量 `DEEPSEEK_API_KEY` 未设置，执行 `python main.py`。
2. 等骑士窗口出现，在输入条说「加个待办：交周报」。
3. 右键打开「我的待办」面板。

**预期现象**

- 待办列表里出现「交周报」，气泡有回应；
- 全程没有真实模型调用（离线规则引擎响应工具意图），闲聊类输入给兜底回复。

### 断言 2：撤销真的把世界改回去，并自证

**操作**

1. 接着断言 1，说「撤销」。
2. 重新打开「我的待办」面板。

**预期现象**

- 「交周报」从待办列表消失；
- 气泡按「退回 N 项 / 没撤成 M 项」口径回报（本例为退回 1 项、没撤成 0 项），明细里标成 `[可撤]`，而不是只说一句「已撤销」；
- 这是每轮开工拍世界快照、收口求差集、按差集下逆操作、撤完再求一次差集自证的结果，见 [ADR 0001](adr/0001-undo-by-world-diff.md)。

### 断言 3：不可逆动作如实说明，不假装全能

**操作**

1. 新开一轮，说「打开计算器」。
2. 等计算器窗口出现后，说「撤销」。

**预期现象**

- 气泡明确说明这一步撤不回，例如「程序我已经帮你打开了，但我不替你关——你窗口里可能有你没存的活儿」；
- 计算器窗口不会被关掉；明细里这一项标成 `[撤不回]`。

### 断言 4：把 Key 改成错的，技能重放照样跑通

> 技能要求一轮内至少 2 个实质动作（`SKILL_MIN_STEPS = 2`），所以先要用一把有效 Key 完成一个多步任务并存下技能；重放阶段才把 Key 改错。

**操作**

1. 配好有效 Key 并启动，完成一个含至少两步的任务，例如说「先加个待办：交周报，再记住：我喜欢深色 PPT」，按计划卡确认执行。
2. 说「存成技能」，气泡应回「学会了：「……」」；说「技能列表」可看到技能名和它需要的槽位。
3. 把 Key 改成明显错误的值：在设置界面改，或 `set DEEPSEEK_API_KEY=invalid` 后重启 `python main.py`，确认真实模型已经不可用。
4. 逐字报出技能名（再说一遍当初那句话）。

**预期现象**

- 技能照样重放：待办 / 记忆按这句话里的新值重新执行；
- 气泡说明「重放「技能名」：N 步，这些步骤直接照当初的动作跑，一步都没再问模型」；
- Key 无效不影响这条路径，因为重放全程不启动 AIWorker。原理与证明手段见 [ADR 0002](adr/0002-skill-replay-zero-llm.md)。

### 断言 5：文档工厂能产出可验收的文件

**操作**

1. 回到无 Key（或任意）状态，说「做个 PPT 介绍凌零」（也可加一句「保存到桌面」直接落盘）。
2. 在弹出的保存位置对话框选好目录，或说「保存到桌面」跳过弹窗。
3. 右键打开「我的交付」面板。

**预期现象**

- 生成一份 `.pptx` 文件并登记进「我的交付」，双击可用系统默认程序打开；
- 无 Key 时内容是离线示例内容，说明文档工厂这条链路不依赖真实模型也能跑通；
- 生成文件不会被误当成用户原有文件被撤销删掉（见 [ADR 0001](adr/0001-undo-by-world-diff.md) 的删文件守卫）。

## 验收判定

5 条断言的预期现象全部出现即通过。任一条不符，请记录气泡原文、当时的 Key 状态与复现步骤。

另外可跑机器校验，注意三类口径不要混称「测试套件」：

| 口径 | 命令 | 实测结果（2026-11-15） |
|---|---|---|
| pytest 单测 | `pytest -q` | 200 passed / 1 skipped |
| tools 集成自检 | `python tools/test_agent_features.py` | 157 通过 / 0 失败 |
| 启动冒烟 | `python main.py --selftest` | 35/35 通过（离屏跳过 2 项布局几何断言） |

CI 还会跑契约检查（`tools/check_contracts.py`）、启动冒烟与端到端能力评测集（`tools/eval_tasks.py`）。完整能力边界见 [架构说明.md](架构说明.md)。
