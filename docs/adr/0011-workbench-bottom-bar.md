# 0011 · 工作台底栏收敛（网页台只留一个输入框，常驻指标撤掉）

- 状态：已采纳（2026-11-20）
- 相关：`ui/workspace_window.py`、`ui/theme.py`、`tests/test_workspace_window.py`、`docs/QUICK_START.md`、[ADR 0005](0005-runtime-capability-switches.md)

## 背景

用户在工作台里指出两件事：

1. 「网页调试台」那一页有**两个输入框**——网页自己那条（`api/static/index.html` 的「说点什么……（Enter 发送）」），加上工作台最底部的全局命令栏。同一屏两个输入框，用户不知道该往哪个里打字。
2. 窗口最底部那一行常驻着七个指标芯片（轮次 / 事件 / 失败率 / token / 偏好 / 生效规则 / 哈希链）和一段模型状态（「本地微调优先 · Qwen/Qwen2.5-1.5B-Instruct（答不上来退 云端 deepseek-reasoner · sk-7f5\*\*\*\*\*）」）。

第二条里那句模型状态还带着掩码后的 Key 片段。它不是安全问题（掩码过），但它说明这一行的定位本来就含混：既像仪表盘，又像状态提示，还夹着一个操作反馈区。

## 决策

### 1. 网页调试台页只留网页自己的输入框

工作台的全局命令栏在「网页调试台」页**收起**，别的页照旧。

- 判据是页 key，不是页序号：`switch_page()` 里按 `PAGE_DEFS[index][0] != "web"` 决定显隐。页面顺序会变（页序号写死过一次就会悄悄点到别人的页），所以走 key。
- 删网页里的输入框是错的：这一页的职责就是「浏览器里那份网页的镜像」，网页调试台没了输入框就不叫调试台了。删的应该是工作台那条重复的。
- 收回来的命令栏不是被禁用，是真的不在这一屏上；切回任何一页它原样回来，`_chat_input` 始终是同一个控件。

### 2. 底部状态栏只留操作反馈

七个指标芯片与模型状态文字全部删掉，状态栏只保留右侧那一句操作反馈（点了有回音的那句）。

- 这条反馈是交互闭环的一部分，不能一起删：关于页的开关翻成功、授权卡收回、交付登记完，都要在这儿说一声。
- 常驻数字移走不等于数据没了：轮次 / 事件 / 失败率 / token 在「执行轨迹」页，偏好与规则在「我的偏好」「学到的规则」页，要看就去那儿看。
- 菜单「复制状态栏文本」改名为「复制运行状态摘要」：`_status_full` 照旧算同一份内容（轮次 / 事件 / 失败率 / token / 偏好 / 规则 / 哈希链 + 模型状态），只是不再常驻显示。要发出去时复制一份即可。
- 随之删掉 `ui/theme.py` 里已无人使用的 `QLabel#statChip` 三条样式；`switchToggle` 是真按钮，样式不受影响（见 ADR 0005）。

## 为什么这样设计

- **一个页面一个主语**：网页调试台里说话的对象是网页，不是工作台。两套输入框都在，等于两个主语。
- **常驻信息要有阅读理由**：七个数字长期占着窗口最下面一条，不看的人每天看，看的人一天看一次。真要盯数字，它该在「执行轨迹」页里，那页本来就是干这个的。
- **删的是展示，不是能力**：指标仍在算、仍能复制，只是不再占据每一屏。能力没退化，噪音少了一处。

## 代价与边界

- 常驻看不到轮次 / 失败率 / token 了：想盯盘得切到「执行轨迹」页，或复制运行状态摘要。
- 「网页调试台」页现在**不能**用工作台命令栏发指令——那一页发指令就是往网页的输入框里打字，走的是网页自己的链路。这正是「桌面与网页是同一个产品」的含义：网页怎么发，工作台里嵌的它就怎么发。
- 命令栏显隐按页 key 判断，将来若再加一页内嵌别的网页，同样适用；若新页也需要自己的输入框，规则照抄。

## 验证

- `tests/test_workspace_window.py`：
  - `test_web_page_shows_only_the_web_input`：切到网页调试台页 `w._cmd_bar.isHidden()` 为真，切回对话页为假；同时断言网页那份 HTML 里确实有「说点什么」输入框，不是空壳页面。
  - `test_status_bar_keeps_only_feedback`：窗口里不再有 `statChip`，状态栏里没有以「轮次 / 事件 / 失败率 / token / 偏好 / 生效规则 / 哈希链」开头的文字，也没有模型状态文字；`_status_full` 里仍能取到「轮次」与「哈希链」，复制摘要这条路没断。
- 手动验收（`docs/QUICK_START.md` 断言 8 第 3 步）：切到网页调试台，底部命令栏消失、网页输入框还在；切回对话页，命令栏回来。
- `pytest -q` 与 `python tools/check_contracts.py` 全绿。
